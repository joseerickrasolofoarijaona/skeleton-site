# Honey Group — Site Web

## Présentation

Ce projet consiste à développer un site web moderne, responsive et modulaire pour **Honey Group**.

Le site présente l'entreprise, ses services, ses projets et permet aux visiteurs de contacter l'entreprise grâce à un formulaire de contact.

## Objectifs du projet

- Présenter Honey Group et ses activités.
- Présenter les différents services proposés.
- Présenter les projets réalisés.
- Fournir une interface moderne et responsive.
- Permettre aux visiteurs d'envoyer un message via le formulaire de contact.
- Organiser le projet avec une structure claire et modulaire.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- PHP
- Composer
- PHPMailer
- SMTP Gmail
- Git / GitHub
